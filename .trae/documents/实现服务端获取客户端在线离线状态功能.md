# 客户端监控功能实现计划

## 一、功能概述

在 `main.py` 中实现客户端监控功能，将视频页面改为客户端监控页面，记录并显示所有连接到服务器的客户端信息。

## 二、实施步骤

### 1. 创建客户端监控界面

* 在 `main.py` 中创建新的 `ClientMonitorWidget` 类，替代现有的 `videoInterface`

* 设计界面布局，包括：

  * 客户端列表（使用 TableWidget，参考文件统计功能的样式）

  * 操作按钮（刷新、删除记录等）

  * 状态统计信息

### 2. 实现客户端连接记录功能

* 在服务器端创建 `client_records.json` 文件存储客户端信息

* 记录内容包括：客户端IP、连接时间、状态、设备信息等

* 每次客户端连接时自动存档

### 3. 实现公网数据上报功能

* 在 `demo.py` 中添加客户端信息上报功能

* 只通过公网地址上报数据到服务器

* 上报内容包括：客户端IP、设备信息、连接状态等

### 4. 实现实时监控功能

* 在 `ClientMonitorWidget` 中添加定时器，定期刷新客户端列表

* 显示在线/离线状态（在线绿色，离线灰色）

* 实时更新连接状态和统计信息

### 5. 实现记录管理功能

* 添加删除记录按钮，支持单个删除和批量删除

* 记录不会自动清空，需要手动删除

* 添加清空所有记录功能

### 6. 界面美化和主题适配

* 参考文件统计功能的 TableWidget 样式

* 实现主题自适应，支持浅色/深色主题

* 添加状态图标和动画效果

### 7. 集成到主窗口

* 在 `MainWindow` 中替换原有的视频页面为新的客户端监控页面

* 更新导航栏图标和文字

* 确保与其他页面的风格统一

## 三、技术要点

1. **数据存储**：使用 JSON 文件存储客户端记录，确保数据持久化
2. **网络通信**：通过公网 API 实现客户端信息上报
3. **界面设计**：参考文件统计功能的 TableWidget 样式，确保美观一致
4. **实时更新**：使用 QTimer 实现定时刷新，确保数据实时性
5. **主题适配**：实现与系统主题同步的界面样式

## 四、预期效果

* 当客户端打开 `demo.py` 时，自动上报信息到服务器

* 服务器 `main.py` 的客户端监控页面实时显示所有连接的客户端

* 显示客户端详细信息，包括 IP、连接时间、状态等

* 支持手动管理客户端记录

* 界面美观，与现有功能风格一致
