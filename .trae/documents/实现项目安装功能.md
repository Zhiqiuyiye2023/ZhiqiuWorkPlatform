# 实现项目安装功能方案

## 1. 项目分析
- 项目是基于PyQt6开发的桌面应用，主入口为`demo.py`
- 依赖项已在`requirements.txt`中列出
- 项目包含`logo.ico`作为应用图标

## 2. 实现方案
### 2.1 打包策略
使用**PyInstaller**将Python项目打包成单个exe文件，然后使用**Inno Setup**制作安装包。

### 2.2 具体步骤

#### 步骤1：安装依赖
确保所有依赖已安装：
```bash
pip install -r requirements.txt
```

#### 步骤2：使用PyInstaller打包项目
创建打包脚本`build.py`，内容如下：
```python
import os
import sys
from PyInstaller.__main__ import run

# 打包配置
params = [
    'demo.py',
    '-F',  # 打包成单个文件
    '-w',  # 无控制台窗口
    '--icon=logo.ico',  # 设置图标
    '-n', '知秋工作平台',  # 应用名称
    '--add-data=qfluentwidgets;qfluentwidgets',  # 包含qfluentwidgets目录
    '--add-data=configs;configs',  # 包含配置文件
    '--add-data=interfaces;interfaces',  # 包含界面文件
    '--add-data=functions;functions',  # 包含功能模块
    '--add-data=automation_tool;automation_tool',  # 包含自动化工具
    '--add-data=gis_workflow;gis_workflow',  # 包含GIS工作流
    '--add-data=news_sources.json;.',  # 包含新闻源配置
    '--clean',  # 清理临时文件
]

run(params)
```

#### 步骤3：创建Inno Setup安装脚本
创建`installer.iss`脚本，配置安装选项：

```iss
; 安装脚本配置
[Setup]
AppName=知秋工作平台
AppVersion=1.0.2
DefaultDirName={pf}\知秋工作平台
DefaultGroupName=知秋工作平台
OutputBaseFilename=知秋工作平台安装包
SetupIconFile=logo.ico
Compression=lzma2
SolidCompression=yes
WizardStyle=modern

; 安装程序语言设置
[Languages]
Name: "chinese"; MessagesFile: "compiler:Default.isl"

; 安装文件配置
[Files]
Source: "dist\知秋工作平台.exe"; DestDir: "{app}"; Flags: ignoreversion
Source: "logo.ico"; DestDir: "{app}"; Flags: ignoreversion

; 桌面快捷方式
[Icons]
Name: "{autodesktop}\知秋工作平台"; Filename: "{app}\知秋工作平台.exe"; WorkingDir: "{app}"; IconFilename: "{app}\logo.ico"
Name: "{group}\知秋工作平台"; Filename: "{app}\知秋工作平台.exe"; WorkingDir: "{app}"; IconFilename: "{app}\logo.ico"
Name: "{group}\卸载知秋工作平台"; Filename: "{uninstallexe}"

; 安装完成页面
[Run]
Filename: "{app}\知秋工作平台.exe"; Description: "启动知秋工作平台"; Flags: postinstall nowait skipifsilent

; 安装程序界面配置
[Setup]
LicenseFile=LICENSE.txt
InfoBeforeFile=README.txt

; 安装进度页面
[InstallDelete]
Type: files; Name: "{app}\知秋工作平台.exe"

; 安装日志
[Setup]
SetupLogging=yes
```

#### 步骤4：准备必要文件
- 创建`LICENSE.txt`：包含软件许可协议
- 创建`README.txt`：包含软件说明和使用指南

#### 步骤5：编译安装包
1. 运行PyInstaller打包脚本：
   ```bash
   python build.py
   ```
2. 使用Inno Setup编译安装脚本：
   ```bash
   iscc installer.iss
   ```

## 3. 安装包功能特性

### 3.1 安装路径设置
- 默认安装路径：`C:\Program Files\知秋工作平台`
- 支持自定义安装路径，用户可在安装过程中修改

### 3.2 快捷方式生成
- 自动在桌面创建带有项目图标的快捷方式
- 在开始菜单中添加程序入口和卸载选项

### 3.3 用户交互界面
- 许可协议确认页面
- 安装路径选择页面
- 安装进度显示页面
- 安装完成提示页面

### 3.4 错误处理
- 磁盘空间检查
- 权限验证
- 安装日志记录

### 3.5 安装完成选项
- 提供"启动知秋工作平台"选项，用户可选择立即启动程序
- 显示安装成功提示

## 4. 优化措施

### 4.1 减小安装包体积
- 使用`lzma2`压缩算法
- 启用`SolidCompression`
- 仅包含必要的依赖文件

### 4.2 提高运行效率
- 使用PyInstaller的`--clean`选项清理临时文件
- 优化导入顺序，减少启动时间

### 4.3 增强用户体验
- 现代化的安装向导界面
- 清晰的安装进度显示
- 详细的安装日志
- 方便的卸载选项
